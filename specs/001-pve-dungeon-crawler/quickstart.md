## Development Workflow

### Starting a New Game

1. Navigate to Hub screen
2. Press "Campaign" button
3. Game screen loads with generated map

### Testing Combat

**Unit test approach:**
```typescript
import { resolveCombat } from '../src/game/combat/resolver';
import { createCombatState } from '../src/game/combat/types';
import { SeededRNG } from '../src/game/engine/rng';

test('combat resolves deterministically', () => {
  const player = createPlayerState({ hp: 20, atk: 5, arm: 2, spd: 3 });
  const enemy = createEnemyState('TUNNEL_RAT', 1);
  const state = createCombatState(player, enemy);

  const result1 = resolveCombat(state, new SeededRNG(12345));
  const result2 = resolveCombat(state, new SeededRNG(12345));

  expect(result1).toEqual(result2); // Same seed = same outcome
});
```

### Testing Map Generation

```typescript
import { generateMap } from '../src/game/map/generator';
import { SeededRNG } from '../src/game/engine/rng';

test('map generation is deterministic', () => {
  const params = { width: 50, height: 50, seed: 42 };

  const map1 = generateMap(params);
  const map2 = generateMap(params);

  expect(map1.tiles).toEqual(map2.tiles);
  expect(map1.enemies).toEqual(map2.enemies);
  expect(map1.pois).toEqual(map2.pois);
});
```

## Debug Features

Debug overlays are available in development builds only (`__DEV__ === true`).

### Enabling Debug Mode

Add to your local environment or use in-app toggle:

```typescript
// In GameScreen.tsx or via dev menu
const [debugState, setDebugState] = useState({
  showFPS: true,
  showSeed: true,
  showStateInspector: false,
  showCombatLog: true,
  showHitboxes: false,
});
```

### Debug Overlays

| Overlay | Description |
|---------|-------------|
| FPS Counter | Shows current frame rate |
| Seed Display | Shows current RNG seed for reproduction |
| State Inspector | Shows full game state JSON |
| Combat Log | Shows last N combat log entries |
| Hitboxes | Shows tile boundaries and entity positions |

### Reproducing a Bug

1. Note the seed value from the debug overlay
2. Create a test with that seed:

```typescript
test('reproduce bug #123', () => {
  const seed = 987654; // From bug report
  const state = initializeGame(seed);

  // Replay actions that caused the bug
  state = gameReducer(state, { type: 'MOVE', direction: 'UP' });
  state = gameReducer(state, { type: 'MOVE', direction: 'UP' });
  // ...

  // Assert expected behavior
  expect(state.player.hp).toBeGreaterThan(0);
});
```

## Common Tasks

### Adding a New Enemy

1. Add definition to `src/data/enemies.ts`:
```typescript
export const NEW_ENEMY: EnemyDefinition = {
  id: 'NEW_ENEMY',
  name: 'New Enemy',
  emoji: '👾',
  tiers: [
    { tier: 1, hp: 5, atk: 2, arm: 0, spd: 2 },
    { tier: 2, hp: 8, atk: 3, arm: 0, spd: 3 },
    { tier: 3, hp: 11, atk: 4, arm: 0, spd: 4 },
  ],
  trait: {
    name: 'Trait Name',
    timing: 'ON_HIT',
    description: 'What the trait does',
    execute: (state, context) => {
      // Trait logic
      return state;
    },
  },
};
```

2. Add to `ENEMIES` array in same file
3. Add unit tests in `__tests__/unit/entities/enemies.test.ts`

### Adding a New Item

1. Add definition to `src/data/gear.ts` or `src/data/tools.ts`
2. If item has an effect, implement in the definition
3. Add unit tests
4. If part of an itemset, update `src/data/itemsets.ts`

### Adding a New POI

1. Add definition to `src/data/pois.ts`
2. Implement interaction handler in `src/game/entities/pois.ts`
3. Add to POI spawn rules in `src/game/map/generator.ts`
4. Add unit tests

## Troubleshooting

### "Cannot find module" errors

```bash
rm -rf node_modules
npm install
```

### Skia rendering issues

Ensure `@shopify/react-native-skia` version matches project:
```bash
npm list @shopify/react-native-skia
```

### Tests failing with "RNG not deterministic"

Check that:
1. No calls to `Math.random()` exist (use `SeededRNG` instead)
2. No `Date.now()` in game logic (use passed-in timestamps)
3. No object key iteration (use arrays or `Object.keys().sort()`)

### Android build fails

```bash
cd android
./gradlew clean
cd ..
npx expo start --android
```
